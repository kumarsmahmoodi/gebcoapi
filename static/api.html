GEBCO Depth Data API

This API allows users to query bathymetric depth data from the GEBCO_2024 dataset for a specified geographic region. You can request a NetCDF file containing depth values and use the service in your own applications or research tools.

Base URL

https://gebcoapi-91108147194.us-central1.run.app

Endpoint

GET /area_depths_netcdf

Query Parameters

  • min_lat (float): Minimum latitude of the area
  • max_lat (float): Maximum latitude of the area
  • min_lon (float): Minimum longitude of the area
  • max_lon (float): Maximum longitude of the area
  • step (float, optional, default = 0.1): Grid resolution in degrees
  • api_key (string, required if authentication is enabled)

Response

The endpoint returns a downloadable NetCDF (.nc) file containing a subset of the GEBCO depth data for the specified region.

Example Request

GET:
https://gebcoapi-91108147194.us-central1.run.app/area_depths_netcdf?min_lat=30&max_lat=35&min_lon=50&max_lon=55&step=0.1

Features

  • Access depth data for any region worldwide
  • Download results as NetCDF for analysis
  • Simple RESTful API for integration
  • Secure access with API keys (if enabled)

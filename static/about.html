About

This web application provides an interactive and powerful interface for accessing global bathymetric data from the GEBCO_2024 dataset. Designed for researchers, oceanographers, engineers, and developers, it allows users to extract and visualize water depths for custom geographic areas directly from the browser. Users can download data in NetCDF format and access API endpoints for integration into their own tools or workflows.
